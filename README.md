# Foodpanda Database Project

A relational database system designed for a food ordering platform.
The project demonstrates database design, SQL, data manipulation,
data querying, integrity constraints, joins, aggregate functions,
and normalization.

## Technologies

- SQL
- Relational Database
- ER Diagram
- Database Normalization

## Project Features

- Customer management
- Restaurant management
- Food/item management
- Order management
- Payment management
- Delivery management
- Relational database design
- SQL queries
- JOIN operations
- Aggregate functions
- Integrity constraints
- Normalization
